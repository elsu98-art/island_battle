# 我的夢想島 Battle BV.3 - 18｜全音效緊急修正版

修正方向：以最後一份原本可用的 BV.3 - 18 音效控制程式為基礎，撤回上一版可能干擾音訊的反覆預播放／恢復監聽。保留三位角色停留 20 秒、特殊攻擊成功音效與原始倒數 WAV。

開始測試：npm install，npm start，開啟 http://localhost:3000/。先確認音樂／音效／環境音，再測試特殊音效與最後 10 秒。

本修正版尚未經由兩台真實裝置驗證所有聲音皆能正常播放。
