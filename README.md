# 我的夢想島 Battle BV.3 - 00｜線上雙人版

這是**需要 Node.js 伺服器**的遊戲，不是雙擊 HTML 即能跨裝置對戰。原始 Three.js 雙島內容保留於 `public/index.html`，且保留答題區與注音顯示。這版改為兩個真實瀏覽器各控制一名玩家，不再有 A 模擬面板。

## 啟動

1. 安裝 Node.js 18 以上版本。
2. 在本資料夾開啟終端機並執行 `npm install`。
3. 執行 `npm start`。
4. 兩個瀏覽器開啟 `http://localhost:3000`（同一電腦測試）。不同裝置需透過區域網路 IP 或將整個專案部署到支援 Node.js 和 WebSocket 的 HTTPS 主機，兩邊開啟相同網址。

## 流程

玩家 A 輸入「房間名稱＋暱稱」並建立房間；玩家 B 以相同房間名稱與自己的暱稱加入。等待室兩人可看到名單與年級，只有 A 可選年級並按 START。按下 START 兩邊同步倒數五秒；播放上傳的系統語音，然後進入五分鐘戰局。遊戲狀態（分數、物件數、攻擊與防護罩）由伺服器驗證並同步。雙方獨立出題，答題、落雷結果透過 WebSocket 同步。

## 已知限制

- 尚未部署到公開網域，也未實際以兩台裝置進行端對端瀏覽器測試。
- 房間暫存於伺服器記憶體，重啟就會清空；任一方斷線會結束房間，尚無斷線重連。
- 建造與落雷透過原有 3D 場景訊息驅動；兩邊採獨立場景顯示，不是真正的共用海面。
- 注音延用原始版本的注音對照，遇到新字或多音字可能無注音或需要校對。
- 房間名稱沒有密碼，請勿視為安全的私人會議空間。正式大規模上線需要部署保護、節流、持久化與防作弊加強。
